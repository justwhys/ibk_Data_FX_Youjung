## 개선 제안 (C안 기준)
1. 큰 숫자 3개를 표 위 가로 한 줄로: "5,684억 × 확인 안 됨 91% × 1% = 52억", 52억만 주황으로 가장 크게. 오른쪽 세로 열 제거, 표 전체 폭
2. 결론 문장 한 줄로 + A안 "지금 40 / 평소 34 · 1.2배" 막대. 방향은 회색 칩(▲21% / ▼19%)만, 빨강·파랑 분할 막대 금지
3. 결론 띠 오른쪽 4개 통화 표 → 경고등 3개 목록. 통화는 원/달러 미니 추이 1줄 또는 탭 3으로
4. 표 정리: "· 수입 결제형" 반복 삭제, 90일 결제 예정 회색 막대 삭제, 13주 미니 차트에 시작·끝 주 라벨, "TOP 5 합계 41억 = 전체 52억의 약 78%" 행 추가, 행 끝 "›"
5. 표 아래 빈 공간에 13주 결제 달력(높이 ~120px, 단위 표시, 선택 행 연동) 또는 행 높이로 900px 채우기

## 세 안 공통 문제
- 제목 "오늘 요약" vs 기준일 11-13(최신) 불일치 → "기준일 요약" 또는 영업일 기준 명시
- 머리말 과다(필터 2줄 + 기준 띠 ≈ 15%), 기준일·가상 데이터 고지 중복 → 필터 1줄, 필터 적용 범위(고객/시장) 표시
- "하위 3%(낮은 편)" — 차트 점 위치와 어긋나 보이고 "낮은 편"은 방향 암시 → 수치만
- 색 규칙 위반: 기준일 점 빨강, 전일 대비 ▼가 주색과 같은 파랑 → 회색/검정
- "실적 증감 +10%" 정의 없음, "+20% 빠르게 증가" 기준 없음
- "1.2배·조금 높음" 근거 눈금(0개 29% · 1개 40% · 2개 52%)을 세 안 모두 한 줄로 고정
- 어투 혼용(~어요 / ~습니다) → 통일
- 회색 보조 글 작고 옅음 → 수 줄이고 대비 높이기
